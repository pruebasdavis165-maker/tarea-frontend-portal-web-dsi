# Portal Web DSI - Consumo PokeAPI
Desarrollado para la asignatura Diseño de Sistemas de Internet.

## Características
- Dos páginas HTML conectadas (`index` y `berries`).
- Consumo asíncrono (Fetch API) de dos endpoints distintos de la PokeAPI.
- Diseños independientes usando CSS Flexbox y Grid (`styles.css` y `berries.css`), manteniendo una cohesión visual con temática Pokémon.
